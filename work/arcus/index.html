Behind the Work

Start with the next session.

A training interface that makes the next action clear: start a session, find an exercise, then return to the log.

The next action, first.

The training dashboard gives session entry priority over secondary tools. The blue action is a consistent reference point in an otherwise restrained dark interface.

A catalogue you can narrow.

The exercise interface exposes search and filters rather than asking the visitor to scan an undifferentiated list. The captures show the actual catalogue interface, separate from personal workout data.

A log on the device.

The source stores workout records and drafts locally and includes account synchronization. Local persistence and remote sync are separate concerns; screenshots of the interface do not establish that the remote service is available.

Scope & Evidence

Shown in a fresh, signed-out browser with no fabricated sessions or activity. Local source was inspected; account synchronization, production authentication and offline recovery are not claimed as verified by these screenshots.

Narrow the next choice.

Search, exercise groups and muscle filters sit together. This close view comes from the actual exercise library, with no personal workout records added for the presentation.
